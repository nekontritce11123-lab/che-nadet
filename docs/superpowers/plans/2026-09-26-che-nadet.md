# «Чё надеть?» Implementation Plan

**Goal:** создать Android-клиент погоды с объяснимым детерминированным советом по одежде.
**Architecture:** независимый `:core`, небольшой `:app`, ручное DI, unidirectional state.
**Tech Stack:** Kotlin, Compose, Material 3, Coroutines/Flow, DataStore, Open-Meteo.
**Spec:** `docs/superpowers/specs/2026-09-26-che-nadet-design.md`.

## Global constraints

Android only; без AI, ключей, рекламы, фоновой геолокации. Осмысленные последовательные commits. Только относящиеся к новому проекту файлы. Не выдавать неисполненный тест за выполненный.

## Review focus

1. Ответ старого запроса при смене города не может перезаписать новый.
2. null / NaN / отрицательные осадки не означают хорошую погоду.
3. Часы устройства и часовой пояс удалённого города не искажают возраст прогноза.
4. Персонализация не подавляет предупреждение об экстремальной жаре/морозе.
5. Отказ в разрешении и отключённый GPS сохраняют доступ к ручному выбору.
